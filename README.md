# Landing Page

A simple and responsive landing page built using **HTML** and **CSS**.  
This project is inspired by *The Odin Project* foundation course.

## 📋 Features
- Responsive layout using Flexbox  
- Clean and modern design  
- Includes sections:
  - Header with navigation links  
  - Hero section with title, subtext, and call-to-action button  
  - Information cards  
  - Quote/testimonial section  
  - Call to action (CTA) box  
  - Footer

## 🧠 What I Learned
- Structuring a webpage using semantic HTML  
- Styling with CSS Flexbox and custom properties (variables)  
- Organizing layouts and spacing using `gap`, `padding`, and `margin`  
- Working with consistent color themes and fonts

## 🛠️ Technologies Used
- HTML5  
- CSS3  
- Google Fonts (Roboto)

## 🚀 How to Run
1. Download or clone the repository.  
2. Open `index.html` in your web browser.  
3. (Optional) Edit `style.css` to customize the design.
